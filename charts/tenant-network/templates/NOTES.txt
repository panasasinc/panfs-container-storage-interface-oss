The PanFS Tenant Network operator is installed in namespace {{ .Release.Namespace }}.

Next steps for a tenant:

1. Label the nodes of the tenant, with a label of your choice:

   kubectl label node <NODE_NAME> <LABEL_KEY>=<LABEL_VALUE>

2. Create a TenantNetwork in the namespace of the Secret that holds the PanAPI address and the token of the tenant:

   apiVersion: panfs.vdura.com/v1alpha1
   kind: TenantNetwork
   metadata:
     name: <NAME>
     namespace: <NAMESPACE>
   spec:
     secretName: <SECRET_NAME>
     nodeSelector:
       <LABEL_KEY>: <LABEL_VALUE>

   Without nodeSelector, all nodes of the cluster are put on the tenant network.

3. Check the result:

   kubectl get tenantnetworks -A
   kubectl -n <NAMESPACE> describe tenantnetwork <NAME>

   A ready node has the label panfs.vdura.com/tenant-network=<NAMESPACE>.
